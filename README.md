# 邕城余生 · Nanning Survivors

> 一个普通打工人，一座沦陷的绿城。进城、搜刮、在尸潮到来前撤离。

致敬《孤单枪手》（Alien Shooter）的 **2.5D 手绘风丧尸生存 · 搜打撤 Roguelite**。舞台是**南宁兴宁区/青秀区老城的真实街道**：朝阳广场、民族大道、中山路、三街两巷、邕江大桥、自治区人民医院……

纯原生 HTML5 Canvas + JavaScript，无需安装、无需构建，**双击 `index.html` 即可游玩**（推荐 Chrome / Edge）。

---

## 背景故事

**2027 年 6 月 28 日，南宁，暴雨。**

江南区一座冷链物流园里，一批来路不明的走私冻品在断电的冷库里化开了。第二天，物流园的分拣工开始高烧、咬人。

疾控把它叫作"急性感染性狂躁综合征"，南宁人管它叫——**"邕江热"**。

感染者的肌肉和骨骼会疯狂增生：有的肿胀如气球，有的肋骨与肌腱撕开皮肤长成**触手**，有的力气大得能**把共享单车、井盖、空调外机抡起来砸人**。一切都是血肉与物理——没有光波，没有魔法，只有失控的身体。

第三天，绕城高速被封锁。第七天，信号中断。老城沦陷。

你叫 **韦小东**，26 岁，宾阳人，原本是那座物流园的**夜班分拣员**。爆发那晚你请假回了出租屋，侥幸活了下来。现在你和一群幸存者躲在**西乡塘的城中村**里，用铁皮和电动车堵住了巷口。

邕江北岸的**民兵卡口**还在运作：用药品、电池、粮食、情报换"撤离积分"。**攒够 50000 积分，就能坐上开往外环安置区的撤离车**——这是游戏的最终目标。

你没有超能力。你有的，只是一把从粉店后厨拿的菜刀。

## 核心循环：搜 · 打 · 撤

1. **备战（城中村据点）**：整理仓库、装备武器护甲、往背包里装进城要用的弹药药品；找阿秦给装备上保险；在老黄的小卖部买卖物资。
2. **潜入**：每天给出 3 条随机路线，每条的**出发点、天气（暴雨/黄昏/停电夜）、城中事件**都不同（肉鸽随机）。
3. **搜**：靠近建筑门口、废弃汽车、外卖电动车、快递柜、尸体，**停下来就会自动搜**，搜到的东西自动进背包（背包满了才会弹出面板让你挑）。建筑种类决定掉落：药店出药、派出所出枪、五金店出射钉枪和油锯、粉店出老友粉……危险度越高的区域，好东西越多。
4. **打**：以走位为主——开局只有西瓜刀 / 水果刀 / 木棍，绕着丧尸走、看准空档用鼠标砍。**噪音系统**：后期捡到的枪声会把整条街的丧尸引过来。
5. **撤**：每局 15 分钟撤离窗口，只开放 3 个撤离点（地铁口、邕江码头冲锋舟、民兵卡口、救援车……）。**第 12 分钟尸潮来袭**。站在撤离点内坚持读条才能撤出。
6. **成败**：撤离成功 → 带回所有物资，经验转化为永久技能点。倒下 → 身上的东西全部丢失（投保物品 70% 概率理赔），只保留三成经验。

**硬核模式**：死亡即删档。

## 操作

操作只有两样：**键盘走位 + 鼠标战斗**。

| 操作 | 功能 |
|---|---|
| WASD | 走位 |
| 鼠标左键 | 朝鼠标方向攻击（按住连砍 / 连射） |
| 鼠标右键 | 翻滚闪避（短暂无敌） |
| 滚轮 | 换武器 |
| 停在门口 / 汽车 / 快递柜旁 | 自动搜刮 |

换弹、止血、吃药、吃饭都会在安全时自动进行。屏幕左上角的「背包 / 地图 / 暂停」按钮可以直接用鼠标点（Tab / M / Esc 也能用）。

**开局武器**：西瓜刀（范围大，一刀扫两只）、水果刀（短但极快）、木棍（最长，击退强），可在据点「装备」里换。

---|---|
| WASD | 移动 |
| 鼠标 | 瞄准 / 左键射击、近战（自动武器按住连射） |
| R | 换弹 |
| E（按住） | 搜索 / 交互 / 救人 |
| 1 / 2 / 3、滚轮 | 主武器 / 副武器 / 近战 |
| G / T | 投掷 / 切换投掷物（红砖、鞭炮、燃烧瓶） |
| 空格 | 翻滚闪避（短暂无敌） |
| Shift | 冲刺 |
| F | 踢击（击退、打断） |
| Q | 专注（需在技能树解锁） |
| H | 智能快速治疗 |
| Tab | 背包 |
| M | 全城地图 |
| Esc | 暂停 |

## 战斗：贴近现实

- 主角是普通人：100 生命，会**流血、饥饿、感染**；没有自然回血（吃饱时极缓慢恢复）。
- 枪械参数按现实设定：弹匣、换弹时间、散布、后坐、射程衰减、移动射击散布变大。**5.8mm 步枪能穿透两个目标**，霰弹枪近距离一枪一个、远了就散。
- 近战消耗体力，体力耗尽会脱力。消防斧能劈两个，开山刀致流血，**油锯持续切割但噪音巨大、耗油**。
- 护甲按部位减伤并有耐久，**防弹背心才挡得住掠夺者的子弹**。
- 感染超过 30% 会自行恶化，到 100% 尸变死亡——抗生素压制、血清清除。

| 类型 | 武器 |

| 近战 | 拳头、菜刀、镀锌钢管、羊角锤、伸缩甩棍、工兵铲、开山刀、消防斧、油锯 |

| 背包 | 红白蓝编织袋、书包、外卖保温箱、登山包、战术背包 |

## 感染者（全部物理流）

| 名称 | 特点 | 对策 |
|---|---|---|
| **行尸** | 慢、数量多 | 近战省子弹 |
| **奔尸** | 飞快、脆 | 别背对它跑 |
| **爬行者** | 贴地潜伏，靠近才现形 | 注意脚下 |
| **肿胀者** | 皮厚，死亡时爆出腐液（伤害+感染+减速，残留毒池） | 远距离击杀，可用来炸尸群 |
| **触手者** | 肋骨肌腱长成触手，3 格外鞭打并把你**拽过去** | 出手前有**红色虚线预警**，翻滚躲开 |
| **投掷者** | 巨臂，**抓起砖头/井盖/共享单车/空调外机**抛投，会预判走位 | 看地上的落点阴影，贴近它或卡视线 |
| **巨尸** | 650 血，蓄力冲锋撞飞一切 | 引它**撞墙会眩晕**，趁机输出 |
| **掠夺者** | 持枪活人，会走位、换弹，也会打丧尸 | 找掩体、穿防弹衣，击杀掉落武器 |

## 成长系统

- **永久技能树**（撤离获得技能点）四大分支：
  - 枪械：稳定射击、快速换弹、专注（主动）、压枪
  - 近战：力气活、耐力、踢门脚、油锯精通
  - 生存：体质、急救常识、跑外卖的腿、免疫力
  - 搜刮：手脚麻利、仓管的眼光、扛包、轻手轻脚
- **局内肉鸽天赋**：每次升级三选一（肾上腺素、翻箱倒柜、运气不错、屠夫、外卖超时冲刺、凝血体质、夜视……共 18 种），撤离或倒下后失效。
- **随机事件**：暴雨、停电夜、黄昏、无人机空投、掠夺者出没、变异潮、尸潮提前、求救信号、难得的安静。

## 地图

地图依据**南宁市兴宁区/青秀区老城真实街道**生成（约 2.9 km × 3.1 km，1 格 ≈ 4 米）：

- 范围：北至人民公园南缘，南至邕江南岸，西至友爱南路，东至民族广场/桃源路一带
- 真实道路：民族大道、朝阳路、人民东路、新民路、民生路、江北大道、友爱南路、桃源路、七星路……
- 真实地标：朝阳广场、民族广场、南宁百货大楼、印象城、和平商场、三街两巷、广西博物馆、自治区人民医院、梦之岛、邕江大桥……
- 道路、水系、建筑轮廓来自 **OpenStreetMap**（谷歌地图数据不允许导出再利用，因此使用同样真实、可合法使用的 OSM 开放数据）；OSM 未覆盖的街区由程序生成城中村自建房、临街商铺（粉店、药店、五金店……）。
- 撤离点/出发点坐标为近似真实位置（地铁站出口、江边、公园门口）。

地图生成脚本见 `tools/gen_map.py`。

## 项目结构

```
index.html          入口
css/style.css       手绘纸张风界面
data/map.js         由 OSM 生成的南宁地图数据
js/util.js          工具与手绘笔触
js/data.js          物品/敌人/技能/天赋/剧情
js/save.js          存档
js/map.js           地图解码、碰撞、视线、流场寻路、分块手绘渲染
js/render.js        2.5D 绘制、角色、光照、小地图
js/entities.js      玩家、感染者 AI、掠夺者、幸存者
js/raid.js          单局：刷怪、噪音、搜刮、事件、撤离
js/ui.js            据点、背包、交易、技能、保险、结算
js/main.js          主循环与输入
tools/gen_map.py    OSM → 地图数据
```

## 画面

- **俯瞰透视城市**：镜头在主角正上方，每栋楼按楼层真实"立起来"：离屏幕中心越远，侧立面露得越多。住宅高层 18–34 层、写字楼 26–46 层、城中村 4–9 层，屋顶有电梯机房、水箱、写字楼停机坪。楼体轮廓由 OSM 数据平滑提取（`tools/gen_outline.py` → `data/outlines.js`）。
- 被高楼挡住的敌人只显示半透明剪影。
- **骨骼动画**：主角、掠夺者、幸存者与行尸/奔尸/触手者/投掷者/巨尸都拆成头、躯干、上下臂、大小腿，有走路摆臂、举刀劈砍、持枪瞄准、翻滚、丧尸蹒跚扑抓、巨尸举臂砸地、受击后仰、倒地动画。
